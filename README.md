# DataScience

Bem-vindo ao repositório **DataScience**, onde reúno estudos, materiais e projetos utilizados em aulas e práticas de Ciência de Dados.

---

## 🎯 Objetivo

- Consolidar fundamentos de análise de dados.
- Aplicar técnicas de Estatística, Machine Learning e Visualização.
- Criar uma base sólida para alunos e estudos futuros.

---

## 💻 Tecnologias

- Python 3
- Jupyter Notebook
- pandas, numpy, matplotlib, seaborn
- Recursos educacionais e notebooks comentados.

---

## 🚀 Como usar

1. Clone o repositório:

   git clone https://github.com/alvespinho/datascience.git
   cd datascience

2. Abra os notebooks:

   jupyter notebook
